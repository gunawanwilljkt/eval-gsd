each `gate`+`Code` row's `command_or_rubric` becomes a task acceptance check the executor runs
as a HARD GATE. `<eval_rows>` carries the contract-row traceability.

## Wave 0 — test infrastructure (eval-first: write the gate before the code)
### T0 — eval harness
- Build `server/test/eval-phase1.mjs`: starts the signaling server on an ephemeral port, drives
  it with built-in `WebSocket` clients, implements checks EC-1..EC-7, takes an `EC-N` arg (runs
  one) or none (runs all), exits non-zero on any failure. Add `npm run eval` → run all.
- acceptance_criteria: `node test/eval-phase1.mjs` runs and **reports red** (server absent) —
  proving the gate discriminates before we build (not a tautology).

- acceptance_criteria:
