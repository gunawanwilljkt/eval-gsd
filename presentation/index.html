Why it exists

AI writes code fast — and drifts fast

Unstructured AI coding loses the plot: scope creeps, “looks right” passes for done, context runs out. GSD wraps the speed in structure so what ships is what you meant.

Install

Up and running in one command

GSD is the .claude/ folder in this repo. You need git, Node.js, and Claude Code — no npm or package manager. Clone it, then drop it into your project.

terminal — install from this repo
# one line — installs into your project
curl -fsSL https://raw.githubusercontent.com/gunawanwilljkt/eval-gsd/main/install.sh \
  | bash -s -- ./my-project

# …or clone and run the installer
git clone https://github.com/gunawanwilljkt/eval-gsd.git
cd eval-gsd
./install.sh ./my-project     # or --global

Then, inside Claude Code

  • /gsd-new-project — scope it: questions → requirements → roadmap
  • /gsd-plan-phase 1 & /gsd-execute-phase 1 — plan and build the first slice, gated by evals
  • /gsd-progress — lost? it always knows what's next
  • /gsd-help — all 67 commands

Installs v1.2.0 — the version in this repo. The installer copies the command set into .claude/ and skips machine-specific hook settings. Update later with git pull && ./install.sh.
